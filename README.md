# Therapist Support

Static source for [therapistsupport.org](https://therapistsupport.org/), hosted and deployed entirely on Cloudflare Pages.

## Local preview

```bash
python3 _dev/serve.py
```

Open `http://localhost:8080`. The development server injects live reload without modifying published files.

## Publish

```bash
./_dev/publish.sh
```

Publishing regenerates the sitemap, runs strict SEO checks, builds a clean public-only directory, and deploys it to the Cloudflare Pages project `therapist-tools`.

The public bundle excludes development tools, research, mockups, caches, dependencies, and source-control metadata. Cloudflare configuration lives in `_headers` and `_redirects`.

## Site standards

- Canonical origin: `https://therapistsupport.org`
- `www` permanently redirects to the canonical origin.
- `/seo/`, `/ops/`, and `/hours/` are operational pages and excluded from search indexing.
- `sitemap.xml` is generated by `_dev/discovery.py`; do not maintain it by hand.
- Design source of truth: `ops/house-style.html`, with implementation notes in `_dev/DESIGN-AUDIT.md`.
- Never publish `_dev/`, `_ops/`, `_to_delete/`, `RESEARCH/`, `mock/`, `node_modules/`, or `_publish/`.

## Preflight checks

```bash
python3 _dev/discovery.py
python3 _dev/seo_rules.py --all --strict
```
