Four ways to open the Simulator

These are not mockups. Each link below opens the real Simulator — same tax engine, same inputs, same saved data — with a different treatment of the navigation and the first screen. Enter a rate in one and it carries into the others.

How to judge them: open each, then ask how long it takes to reach the hourly-rate field, and whether you can tell where you are in the site. The current layout spends 40% of a 900px-tall screen on chrome before the first input.
01

The hero is deleted. The wordmark carries the page identity with "California · 2026 net estimates" underneath, and the destinations move back out to the right edge. One sentence of description survives; the controls start almost immediately.

Worth knowing before you test

  1. They share one engine. Every variant is the same app.js with a different layout class — no forked copies to drift apart, and every number is the real calculation.
  2. Your data follows you. All variants read the same saved setup, so enter a rate once and compare like for like.
  3. 01 and 02 combine. They fix different things and don't conflict — 01 removes the wasted height, 02 gives what's left a job. Measured on a 900px screen: 01 alone takes chrome from 40% to 24%; adding 02's inline panel keeps that height while giving it something to say.
  4. Nothing here is permanent. Removing the ?v= parameter returns the current layout, so the live site is unaffected while you decide.
