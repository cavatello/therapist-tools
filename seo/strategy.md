# Therapist Support organic growth strategy

Baseline: August 18, 2026. Sources: GA4 property `549050855`, Google Search Console URL-prefix property, repository audit. Ahrefs API access is connected but the current subscription does not permit Site Explorer API calls.

## North-star outcome

Build the most useful California-specific operating library for therapists, then turn qualified search visits into newsletter subscribers and repeat tool users. The 12-month goal is durable non-brand growth—not page count: 25,000 monthly organic impressions, 1,250 organic clicks, 4%+ CTR on queries ranking in positions 1–10, and a measurable 3%+ visitor-to-subscriber rate.

## Positioning

Therapist Support should own the practical layer between regulation and a therapist's working life: what a rule, fee, reimbursement rate, degree choice, or tax decision means in dollars, hours, and next actions. The defensible advantage is California specificity, transparent sourcing, calculators, and tables that are maintained when inputs change.

## Topic architecture

1. **California licensure economics:** BBS fees, 3,000 hours, associate renewals, supervision cost, exam timelines, practicum and program comparisons.
2. **Therapist income and getting paid:** reimbursement rates, private-pay benchmarks, panel comparisons, county salaries, unpaid hours, superbills, and negotiating offers.
3. **Private-practice operations:** entity choice, taxes, retirement plans, liability coverage, telehealth, records, hiring an associate, and practice software.
4. **Training and career decisions:** California MFT programs, ROI, psychedelic training, continuing education, and employer directories.

Each cluster needs one decision-oriented pillar, supporting answers to narrow questions, two-way internal links, and one primary conversion action.

## Editorial standards

- One clear search intent and primary query per page; answer it in the first 100 words.
- Prefer original calculations, comparison tables, tools, and primary sources over generic advice.
- Put the date checked beside volatile figures. Create an update owner and cadence for every financial or regulatory page.
- Use a descriptive title under 60 characters, a compelling description under 160 characters, one H1, useful subheads, canonical URL, Article/Breadcrumb schema, and 3–6 contextual internal links.
- Medical, legal, tax, and financial claims require primary sourcing and careful scope language. Avoid implying individualized professional advice.
- Do not mass-publish thin AI articles. A page ships only if it adds a sourced fact, computation, dataset, firsthand method, or clearer decision framework than the current results.

## First 12 weeks

### Weeks 1–2: foundations and quick wins

- Correct the GA4 web-stream default URL (`therapsitsupport.org` → `therapistsupport.org`).
- Mark `newsletter_signup` and `contact_message` as GA4 key events; add outbound-source and calculator-completion events.
- Inspect the homepage, sitemap leaders, and several zero-click pages in Search Console. Reconcile the 244 submitted / 0 indexed sitemap report.
- Improve snippets on the BBS fees, rates, psychedelic training, insurance reimbursement, and 3,000-hours pages.
- Add internal links from relevant hub pages to the five highest-impression pages.

### Weeks 3–6: publish the first cluster

Build the licensure-cost cluster around the existing BBS fees and 3,000-hours assets:

- California LMFT license renewal cost: every fee and deadline
- AMFT renewal: timeline, late renewal, six-year limit, and law-and-ethics rule
- Cost to become an LMFT in California: tuition excluded vs. full economic cost
- Paying for supervision: employee, volunteer, and private-supervision scenarios
- BBS fee calculator and annual update page

### Weeks 7–10: capture commercial intent

Expand reimbursement and practice-operations comparisons. Refresh the rates dataset, create carrier-specific explainers only where evidence is adequate, compare platforms without affiliate-first rankings, and link every page to an appropriate calculator or decision guide.

### Weeks 11–12: distribution and authority

Package the strongest data as embeddable tables and concise pitches. Outreach targets: California graduate programs, practicum offices, clinical supervisors, CAMFT chapters, therapist newsletters, and workforce-development organizations. Lead with a useful dataset or calculator, not a request for a link.

## Reporting cadence

Weekly: clicks, impressions, page-one CTR, new indexed pages, top query/page movers, subscriber conversions, broken links, and publishing status. Monthly: cluster-level traffic, conversion rate, assisted conversions, referring domains, update compliance, and content decay. Quarterly: prune or merge weak pages, refresh volatile data, and reset targets using the prior quarter's actuals.
